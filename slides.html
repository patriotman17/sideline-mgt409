Safety

Wrong stats, spoilers and bills

  • Injection: user text is data; the provider filter blocks jailbreaks; blocked text is never resent.
  • Made-up facts: any number no tool returned is flagged; evidence must cite a tool that ran.
  • Spoilers: tools can't see the future; answers stating an unreached final score are withheld; the database refuses future rows.
  • Overspending: $2/day budget cap, rate limits, ≤5 model requests and 700 output tokens per question.
  • Data: private Supabase schema, row-level security, read-only backend role. 291 + 63 tests pass.
