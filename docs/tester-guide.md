# Try Sideline: a 10-minute test

Thanks for helping! **Sideline** is an AI companion for watching NFL games. It explains what's happening as it
happens, answers any football question from real data, and asks you to call the big moments.

For this test it replays a real week of the NFL (2025, Week 5) on a live clock, so the games play out exactly as they
really did. Nothing is spoiled: you only see what has "happened" so far.

## 1. Open it
- **Link:** https://sideline-web.onrender.com (phone or laptop).
- The first load can take **up to a minute** while the server wakes up. You'll see "Waking up the Sideline server…".
- Tap **Try Demo**. No account is needed.
- On iPhone, for a full-screen app: Safari → Share → **Add to Home Screen**.

## 2. Start the games
On **Scores**:
1. Under **Jump to**, tap **Sunday · 1:00 PM**.
2. Pick a speed: **60×** is one game hour per minute.
3. Press the lime **▶** button. The games go live and the scores update on their own.

## 3. Try these (about 5 minutes)
1. **Open a live game** (for example Broncos @ Eagles). It stays in sync with the clock.
2. In the game, open **Ask AI** and ask something like: *"Who has the most rushing yards so far?"* or *"Why did they punt there?"*
3. If the game **pauses for a big moment** (a 4th down, a key drive), make your call before the timer runs out.
4. Open a game that **hasn't started yet** (for example Patriots @ Bills) to see the **pregame** card and AI preview.
5. Tap the lime **Ask** button (bottom right) and ask any football question:
   - *"What's a two-point conversion?"*
   - *"Who has the best defense this season?"*
   - *"How did the 2007 Patriots do?"*

The **Picks**, **Party** and **Discover** tabs are previews of upcoming features with sample data. Feel free to look,
but the real features are the ones above.
